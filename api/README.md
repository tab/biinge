# Biinge API

Go REST API for [biinge](../README.md): user auth, a movie, TV and game
library, episode-level progress, an Up Next queue, statistics, cached TMDB and
IGDB proxies, and Jellyfin played-state sync.
Serves `/api/v1` on `:8080`.

## Tech stack

- **Go** with [Fx](https://github.com/uber-go/fx) for dependency injection
- **[Chi](https://github.com/go-chi/chi)** router with JWT auth
- **PostgreSQL** via [pgx](https://github.com/jackc/pgx); queries generated by [sqlc](https://sqlc.dev), migrations by [goose](https://github.com/pressly/goose)
- **Redis** (optional): caches TMDB and IGDB responses, statistics and Jellyfin library reads
- **[TMDB](https://developer.themoviedb.org)** for movie and TV metadata
- **[IGDB](https://api-docs.igdb.com)** for game metadata
- **[Jellyfin](https://jellyfin.org)** (optional) for sign-in, library matching and two-way played-state sync

## Prerequisites

- Go (see [`go.mod`](go.mod) for the version) and Docker (for Postgres + Redis)
- CLI tools: [`goose`](https://github.com/pressly/goose), [`sqlc`](https://sqlc.dev), [`golangci-lint`](https://golangci-lint.run)

## Configuration

Env files live in this directory. `.env.development` is committed with `SECRET`
placeholders; put real secrets in `.env.development.local` (gitignored), which
overrides it.

| Variable                                | Purpose                                                      |
| --------------------------------------- | ------------------------------------------------------------ |
| `DATABASE_DSN`                          | Postgres connection string                                   |
| `REDIS_URL`                             | Redis URL for the TMDB, IGDB, stats and Jellyfin cache       |
| `TMDB_API_READ_ACCESS_TOKEN`            | TMDB v4 read token (required for detail/search/trending)     |
| `IGDB_CLIENT_ID` / `IGDB_CLIENT_SECRET` | Twitch app credentials for IGDB (required outside dev)       |
| `JWT_SECRET_KEY`                        | token signing secret                                         |
| `JELLYFIN_BASE_URL`                     | this instance's Jellyfin server (optional)                   |
| `JELLYFIN_TOKEN_KEY`                    | 32-byte key for stored Jellyfin tokens (required with it)    |
| `JELLYFIN_SYNC_ENABLED`                 | runs the Jellyfin sync worker (default `false`)              |
| `JELLYFIN_SYNC_INTERVAL`                | Jellyfin poll interval (default `2m`)                        |
| `JELLYFIN_RECONCILE_INTERVAL`           | Jellyfin reconcile interval (default `1h`)                   |
| `SENTRY_DSN`                            | error reporting (optional)                                   |

Jellyfin watched state syncs both ways. The API writes each biinge mark to
Jellyfin. A worker polls every connected user's Jellyfin played states each
`JELLYFIN_SYNC_INTERVAL` and applies the changes to biinge, adding a title that
is played in Jellyfin but not tracked in biinge. Each `JELLYFIN_RECONCILE_INTERVAL`
the worker also writes biinge's state to the Jellyfin items that differ, so
biinge wins. A Jellyfin mark made while the API is down is reverted by the first
reconcile after it returns. The worker runs only with `JELLYFIN_SYNC_ENABLED=true`.
The first pass pushes biinge's state to Jellyfin, so back up Jellyfin before
enabling it.

## Database

Start the datastores (from the repo root) and apply migrations:

```sh
docker compose up -d database redis   # Postgres :5432, Redis :6379
make db:migrate                       # GO_ENV defaults to development
make db:migrate:status
make db:rollback                      # roll back the last migration
```

After editing SQL under `db/sqlc/`, regenerate the typed query layer:

```sh
sqlc generate
```

`db/schema.sql` is the canonical pg_dump of the schema; refresh it with
`make db:schema:dump` after adding a migration.

## Run

```sh
GO_ENV=development go run ./cmd/biinge   # http://localhost:8080
```

Alternatives:

- `make run`: full stack (API + Postgres + Redis) via docker compose

Health: `GET /health` · Readiness: `GET /ready` · API base: `/api/v1`. The full
contract is in [`api/swagger.yaml`](api/swagger.yaml).

## Development

`make check` runs the full pre-commit loop, which is everything CI checks:

```sh
make check    # fmt + lint + test + test:race
```

Individual targets: `make fmt`, `make lint`, `make test`, `make test:race`,
`make coverage`. Tests run against a live `biinge-test` database (`GO_ENV=test`).
`make vet` also exists, but `make lint` covers it:
`.golangci.yaml` enables govet and staticcheck as linters.
